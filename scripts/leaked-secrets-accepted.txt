# Um segredo partilhado escrito dentro de um manifesto não tem caminho próprio:
# está numa linha de um `.yaml`. Tirá-lo da árvore não o tira do histórico, e
# este repositório é público — está queimado desde o primeiro push.

# server/src/config.rs). As duas metades são precisas: o portão impede que
# volte ao repositório, o servidor impede que um cluster antigo o continue a
# usar.
#

#   # razão, decisão, data (linhas de comentário a seguir)
